# Archived scripts

One-shot migrations, historical audits, and pre-vitest manual test harnesses,
kept for reference only. Nothing here is wired to npm scripts, CI, or deploy,
and the directory is excluded from `tsc` — expect bit-rot. The `test_*.ts`
files predate the real vitest suites next to the source (`src/**/*.test.ts`);
the backfill/cutover scripts reference migrations that have already run.
